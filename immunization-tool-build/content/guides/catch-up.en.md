# Catching up on missed doses

Missing a dose is common, and it can almost always be fixed. A vaccine series **doesn't need to start over**, no matter how much time has passed.

## How catching up works

- Your pediatrician picks up where your child left off.
- Some doses need a minimum amount of time between them, so catching up can take a few visits.
- Several vaccines can usually be given at the same visit.

## What you can do now

- Bring any records you have to the next visit. If you're missing some, see [Finding old records](/vaccines/guides/finding-old-records).
- Add what you know to your child's record, or [scan a record](app:scan).
- Write down questions for the pediatrician in Visit Prep.
