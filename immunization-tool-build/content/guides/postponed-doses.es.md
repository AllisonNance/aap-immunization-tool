# Cuando se pospone una dosis

A veces se pospone una dosis, por ejemplo porque su hijo tiene una enfermedad moderada o grave. Un resfriado leve normalmente no es motivo para esperar.

## Qué pasa después

- Ponga una nueva fecha para la dosis en el registro de su hijo.
- Las dosis siguientes pueden moverse, para mantener el tiempo correcto entre ellas.
- La serie no tiene que empezar de nuevo.

Pregunte a su pediatra cuándo es un buen momento para volver a programarla.
